# 個人記録（プライベート）

仕事とは分けて管理する個人用リポジトリ。

## 歩数
- 記録ファイル: `health/log.csv`（1日1行：日付 / 歩数 / メモ）
- 記録のしかた: iPhone「ヘルスケア」の歩数画面のスクショを Claude に送るだけ。
  - 日付と歩数を読み取って追記・保存する。
  - 週表示・月表示のスクショなら複数日まとめて登録。
  - 同じ日付がすでにあれば上書き。

## 天気（歩数と並べて記録）
- 出典: 気象庁「過去の気象データ」日別値
  - 天気(昼)・最高気温・降水量(赤坂): 東京観測点（北の丸公園／赤坂から約3km）
  - 降水量(桜丘): 世田谷観測点（アメダス／桜丘から約1km）※雨量のみの観測点
- 天気は当日分の確定後（翌日以降）に追記する。
